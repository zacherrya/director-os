# Director OS

The creative command centre for short-form filmmakers. Take an idea and turn it into a complete, second-by-second production plan before you ever pick up a camera.

## Stack

React 19 + TypeScript + Vite, Tailwind CSS v4, Zustand, Framer Motion, dnd-kit, React Router, lucide-react.

## Getting started

```bash
npm install
npm run dev
```

## What's here (v1)

- **Projects Dashboard** — unlimited projects, each with its own episodes.
- **Episode Timeline** — the main planning surface: a clickable second-by-second timeline plus a full scene table and a scene detail panel (Purpose, Emotion, Camera, Visual, On-Screen Text, Dialogue, Actor Direction, Audio/SFX, Retention Goal, Notes, AI Assets).
- **Storyboard View** — drag-and-drop visual cards for the same scenes.
- **Asset Manager** — every AI video, image, music, SFX, font, logo, icon, prop, and wardrobe item in a project, with status and linked scenes.

Dark mode by default with a warm cream/gold/charcoal palette; a light theme is available via the toggle in the sidebar. Episodes, Templates, and Analytics are shown as placeholders for a future pass.
